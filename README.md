# Морской бой: исследование тактик

Симулятор классического морского боя (поле 10×10, флот 5-4-3-3-2, 17 клеток,
корабли не касаются друг друга ни сторонами, ни углами) с веб-интерфейсом. Цель — сравнить тактики атаки по числу выстрелов до победы
на больших выборках, включая нестандартные подходы.

Выводы — в [RESEARCH.md](RESEARCH.md). Сырые данные и автоматические таблицы — в `results/`.

## Запуск

Нужен только Python 3.10+ (сторонних пакетов нет).

```bash
# веб-интерфейс: реплей партии, запуск турниров, таблицы и гистограммы
python3 -m battleship serve            # http://127.0.0.1:8000/

# пакетный прогон без UI (по умолчанию 500 партий на пару)
python3 -m battleship tournament --games 1000 --out results/tournament.json

# markdown-отчёт по сохранённому прогону
python3 -m battleship.report results/tournament.json > results/report.md

# поиск лучшей расстановки против PD (результат — results/best_layout_pd_hint.json)
python3 -m battleship.search pd_hint

# maximin-расстановка по набору тактик
python3 -m battleship.search robust pd_hint pd_plain parity_hunt random_hunt sonar_hunt lattice_hunt pd_edge_prior pd_center_prior pd_parity

# картинки (тепловые карты и графики; нужен matplotlib) -> results/figures/
python3 -m battleship.figures

# тесты
python3 -m unittest discover -s tests -v
```

## Структура

|---|---|
| `battleship/engine.py` | поле, флот, ход партии (`play`), журнал выстрелов |
| `battleship/strategies.py` | тактики атаки и их сборка (idle-политика + добивание) |
| `battleship/placements.py` | стратегии расстановки защитника |
| `battleship/search.py` | поиск расстановки флота: против одной тактики или maximin по набору |
| `battleship/tournament.py` | многопроцессный прогон, сводная статистика, парные разности |
| `battleship/report.py` | markdown-отчёт |
| `battleship/figures.py` | картинки: тепловые карты, матрица, рейтинг, распределения (matplotlib) |

| `tests/test_engine.py` | проверки корректности расстановок, ходов и тактик |

## Как устроены сравнения

- Правило «корабли не касаются» — в движке и в генераторах расстановок. Клетки, пустота которых
  следует из правила (диагонали подбитой клетки, окружение потопленного корабля), движок сам
  помечает на доске атакующего (идеальный учёт). `play(..., deduce=False)` отключает это.
- Атакующие **не видят** расстановку. Тактика получает только свою доску и
  размеры ещё не потопленных кораблей (в сообщении «потоплен» они известны).
- Все тактики на одной паре (расстановка, seed) играют **один и тот же флот** —
  сравнение парное, шум сильно меньше.
- Генераторы детерминированы: `random.Random("layout|<расстановка>|<seed>")` и
  `random.Random("attack|<тактика>|<расстановка>|<seed>")`. Прогон воспроизводим.
- Метрика — число выстрелов до последнего попадания. Ниже — лучше.

## Тактика = idle-политика + добивание

Простая «охота» состоит из двух частей: что стрелять, пока нет подбитых
клеток (idle), и как добивать корабль (finisher). Это позволяет менять
паттерн поиска отдельно от добивания. PD-тактики объединяют обе части
в одну функцию, потому что учитывают попадания напрямую.

## Расширение

Новая тактика — функция `choose(grid, remaining, rng) -> индекс клетки`, которую
нужно зарегистрировать через `_register(...)` в `strategies.py`. `grid` — список
из 100 значений `UNKNOWN / MISS / HIT / SUNK`, `remaining` — длины непотопленных
кораблей. Новая расстановка защитника — вес положения в `WEIGHTS` (`placements.py`).
